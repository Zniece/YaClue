# YaClue v0.1.0-alpha.4

Release date: 2026-09-14.

Alpha 4 is the first release based on YaClue's typed semantic core. It replaces
the former patch-oriented processing paths with a structured mathematical-object
pipeline while retaining Yacas as the symbolic computation engine.

## Highlights

- Typed mathematical objects, capabilities, partial applications, and explicit
  held/no-value/effect outcomes;
- AST-native inside-out composition and normalization between operations;
- structured results for limits, derivatives, integrals, equations, ODEs,
  algebra, numerical methods, linear algebra, multivariate calculus, and plots;
- separate product channels for equivalent transformations, mathematical
  analyses, terminal conclusions, and effects;
- normalized equation and ODE explanations that no longer connect auxiliary
  calculations or alternative branches with false equivalence arrows;
- composable symbolic results, including unevaluated mathematical operators
  that can be consumed by later transformations;
- JSON Lines and GUI paths backed by the same structured processing result.

## Validation

The release gate is:

```text
./scripts/test-gate.sh release
```

It checks formatting, Clippy with warnings denied, frontend syntax, workspace
tests, documentation tests, architectural dependency rules, structured release
contracts, and representative end-to-end compositions.

## Distribution

The prerelease workflow builds Linux x86_64 packages, a macOS Apple Silicon
application and DMG, a Windows x86_64 installer, and an Android arm64 APK.
The Android artifact uses an ephemeral testing key and is intended only for
direct evaluation, not app-store distribution.

Alpha 4 remains a prerelease. Mathematical coverage and presentation details
will continue to evolve, but the semantic backend and product result contract
are now the baseline for subsequent work.

The obsolete external C++ REPL adapter has been removed. Alpha 4 uses the
in-process Rust Yacas engine exclusively; upstream C++ compatibility is not a
supported runtime contract.
