# YaClue 0.1.0-alpha.5

## 简体中文

这个预发布版将计算器界面更新为 MathLive 数学输入，提供按功能分组的屏幕键盘、可收起的键盘区域，以及输入、步骤和答案分开的数学行。步骤和较长表达式可在各自区域滚动查看。菜单提供中英文切换、输入帮助和 YaClue 表达式直输；点击帮助中的示例也可直接进入表达式直输。

输入支持常见算术、函数、方程、微积分、矩阵与向量运算。可以使用 `==` 构造方程、用 `Solve` 显式求解；在表达式后以分号附加仅对本次计算生效的假设，例如 `Sqrt(x^2);x>0`。部分运算支持等待补全的输入。具体形式见应用内帮助或 [YaClue 数学输入文档](../yaclue-input-zh.md)。

这是测试版本，数学输入合法不代表一定能得到封闭形式答案。无法完成的运算可能保留为未决数学对象。某些复杂输入仍可能需要使用明确的函数形式。

提供 Linux、macOS 和 Windows 桌面安装包，以及 Android arm64 测试 APK。macOS 包未经过 Apple 公证，系统可能要求手动确认打开。Android APK 使用临时测试密钥签名，不适用于应用商店；从旧预发布版升级时，签名不同可能要求先卸载旧版，卸载会清除该应用的本地数据。

## English

This prerelease introduces MathLive mathematical input, a grouped on-screen keyboard, a collapsible keyboard area, and separate math rows for input, steps, and answer. Long steps and expressions scroll within their own areas. The menu includes English and Simplified Chinese, input help, and direct YaClue expression input. Help examples can be opened in the direct-input view.

Input covers common arithmetic, functions, equations, calculus, matrices, and vectors. Use `==` to construct an equation and `Solve` to solve it explicitly. A semicolon can attach assumptions for one calculation, for example `Sqrt(x^2);x>0`. Some operations accept partial input. See the in-app help or the [YaClue mathematical input guide](../yaclue-input.md) for details.

This is a test release. Valid input does not guarantee a closed-form answer; unsupported calculations may remain unresolved mathematical objects. Some complex input still requires an explicit function form.

Desktop packages are available for Linux, macOS, and Windows, alongside an Android arm64 test APK. The macOS package is not Apple-notarized and may require manual confirmation to open. The Android APK uses a temporary test signing key and is not an app-store package. Upgrading from an earlier prerelease may require uninstalling it first because its signing key differs; uninstalling clears the app's local data.
