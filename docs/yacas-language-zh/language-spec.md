# Yacas 脚本语言规范

本文定义 YaClue 所维护的 Yacas 脚本语言。“必须”表示实现和脚本可以依赖的行为；详细手册中未被本文或测试覆盖的历史条目不自动成为语言核心要求。

## 1. 程序与语句

Yacas 源文件由以分号 `;` 结束的表达式组成。装载器按顺序解析并求值，前面的语句可以声明后续语句使用的运算符、变量和规则。

```ys
x := 2;
f(t) := t^2;
f(x);
```

`//` 引入行注释，`/* ... */` 引入块注释。标识符区分大小写。产品输入框通常只接受一个表达式；这属于产品契约，不限制 `.ys` 文件包含多条语句。

## 2. 对象模型

语言值形成表达式树：

- **数值**：任意精度整数和十进制数；
- **符号**：变量、常量或函数名，如 `x`、`Pi`、`Sin`；
- **字符串**：双引号包围的文本；
- **调用**：头部和参数，如 `f(x,y)`；
- **列表**：`{a,b}` 是 `List(a,b)` 的表面语法；
- **容器**：数组和关联表由核心命令创建。

未知符号是合法值。未知函数不会产生“未声明函数”错误，而是以求值过参数的调用形式保留。这使表达式可以同时充当数据和程序。

## 3. 表面语法

函数调用写作 `head(arg1,arg2,...)`。前缀、后缀、中缀和 bodied 运算符由环境中的运算符表决定。

```ys
a+b*c;
-x;
n!;
D(x) Sin(x);
```

`Infix`、`Prefix`、`Postfix`、`Bodied`、`RightAssociative` 及优先级命令可以修改运算符表。声明只影响此后解析的文本。`[a; b; c;]` 是顺序块，等价于 `Prog(a,b,c)`，结果为最后一个表达式的值。

## 4. 求值模型

求值以环境和表达式树为输入，返回表达式树或结构化错误。

### 原子

数值和字符串求值为自身。符号先查局部绑定，再查全局绑定；没有绑定时返回自身。普通绑定保存的表达式在读取时不会自动反复求值。惰性全局绑定在首次读取时求值并缓存。

### 调用

调用的处理顺序是：

1. 查找同名核心命令；
2. 查找相同名称和参数个数的规则库，必要时通过 `.def` 延迟装载；
3. 若无适用实现，求值参数并保留原调用头。

核心命令自行决定参数求值方式。规则库默认先求值参数；`HoldArg` 可以禁止指定参数的预求值。规则按优先级和条件选择，规则体的结果继续进入求值流程。

### 保持与未完成计算

`Hold(expr)` 阻止 `expr` 在当前边界继续求值，`Eval(expr)` 显式触发求值。多层 `Hold`、宏参数与反引号会改变求值次数，规则不能假设所有参数总是恰好求值一次。

符号计算无法继续时通常返回未求值表达式。这是正常结果。类型错误、无效参数、解析失败、深度耗尽和用户中断通过错误返回。

## 5. 变量与作用域

`:=` 是标准脚本提供的定义语法，最终使用核心赋值和规则命令。`Local` 与 `MacroLocal` 声明当前帧中的局部名，局部绑定遮蔽全局绑定。

```ys
f(x) := [
    Local(y);
    y := x+1;
    y^2;
];
```

构造稍后重新求值的表达式时，应使用 `LocalSymbols` 或 `TemplateFunction` 避免形参与调用环境发生名字碰撞。`Protect`、`UnProtect` 和 `IsProtected` 管理受保护符号。

## 6. 规则系统

函数由名称与参数个数共同标识。`RuleBase` 声明普通规则库，`MacroRuleBase` 声明宏规则库；Listed 变体接收列表形式的参数。

```ys
RuleBase("double", {x});
Rule("double", 1, 10, True) 2*x;
```

常用定义和规则语法会展开为核心命令：

```ys
double(x) := 2*x;
10 # double(_x) <-- 2*x;
```

模式参数、谓词和优先级共同决定规则是否适用。`RulePattern` 支持预构造模式，`Retract(name,arity)` 删除规则库。规则没有匹配项时，调用保持未求值。递归规则必须缩小问题或受明确上限约束。

## 7. 核心与标准脚本

核心命令由 Rust 的 `commands::register_core_commands` 注册，提供：

- 赋值、局部变量、保护和环境查询；
- 控制流、保持、显式求值和错误捕获；
- 规则库、模式、替换及运算符表；
- 基础数值、整数、字符串、列表、数组和关联表；
- 文件装载、输入输出、解析和调试钩子；
- 假设上下文和有界求值。

标准脚本位于 `yacas/scripts`，实现算术规范化、初等函数、微积分、方程、ODE 和线性代数等高层能力。脚本函数与核心命令调用外观相同，但实现层级和稳定性不同。注册表以 Rust 源码为准。

## 8. 脚本与延迟装载

宿主建立 `Environment` 后，设置脚本目录并装载 `yacasinit.ys`。启动文件装载基础语法和定义；其他包通过 `.def` 登记函数名，在首次调用时装载。

```ys
DefaultDirectory("/path/to/scripts/");
Load("yacasinit.ys");
```

`.def` 是索引而非实现。包通常采用 `name.rep/code.ys` 和相应 `.def`。`Load` 装载指定文件，`Use` 避免重复装载。

## 9. 数值、错误与资源限制

环境保存当前十进制精度。精确整数与任意精度小数由 Rust 数值层表示；标准脚本决定何时保留符号或进入近似计算。`N` 是标准脚本的数值化入口，底层算法可以使用 `Math*`、`Fast*` 和精度命令减少调度。

解析器、核心命令和求值器返回 `YacasError`。脚本可用 `Check` 报告错误，并用 `TrapError`、`GetCoreError` 或标准库工具处理。错误展开由 Rust 求值器和环境帧管理。

宿主可以设置截止时间，求值器和长循环核心命令会检查它；超时表现为 `UserInterrupt`。最大求值深度防止无界递归。文件与进程命令还受安全作用域约束。

## 10. 符合性

语言符合性由以下可执行资料确定：

- `yacas/yacas-rs/tests`：解析器、求值器和核心命令；
- `yacas/tests/*.yts`：标准脚本行为；
- Rust 模块单元测试：数据结构、数值层及资源边界。

文档与测试冲突时，应判断实现缺陷或文档过时，并在同一修复中更新两者。
